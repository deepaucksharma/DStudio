Pronunciation Guide

Learn how to pronounce technical terms in Hindi. Audio recordings and phonetic spellings included.

Algorithm

एल्गोरिदम / अल्गोरिदम

al-go-ri-dhum

A step-by-step procedure for calculations, data processing, and automated reasoning tasks.

Sorting Algorithm Search Algorithm

Database

डेटाबेस / आंकड़ा आधार

de-ta-beys

A structured collection of data that is stored and accessed electronically.

MySQL MongoDB PostgreSQL

API

एपीआई / एप्लिकेशन प्रोग्रामिंग इंटरफेस

ey-pee-aai

Application Programming Interface - a set of protocols for building and integrating application software.

REST API GraphQL WebSocket

Authentication

ऑथेंटिकेशन / प्रमाणीकरण

aw-then-ti-key-shun

The process of verifying the identity of a user, process, or device.

OAuth JWT 2FA

Kubernetes

कुबेरनेटेस / के8एस

koo-ber-ne-tes

An open-source container orchestration platform for automating deployment, scaling, and management of containerized applications.

Pods Services Deployments

Framework

फ्रेमवर्क / ढांचा

frem-wurk

A platform for developing software applications. It provides a foundation structure for building applications.

React Django Spring
