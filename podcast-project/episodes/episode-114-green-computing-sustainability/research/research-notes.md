## 2. Power Usage Effectiveness (PUE) Optimization

### Understanding PUE in Indian Context

**Power Usage Effectiveness (PUE)** measures data center energy efficiency:
```
PUE = Total Facility Energy / IT Equipment Energy
```

**Global and Indian PUE Benchmarks:**
- Google data centers: PUE 1.10 (2024)
- Microsoft Azure: PUE 1.125 (2024)
- AWS global average: PUE 1.135 (2024)
- **Indian data center average**: PUE 1.8-2.2 (2024)
- **Target for green Indian DCs**: PUE < 1.3 by 2027

class DataCenterEnergyOptimizer:
    def __init__(self):
        self.sensors = IoTSensorNetwork()
        self.ml_models = EnergyPredictionModels()
        self.control_systems = FacilityControllers()
        self.weather_api = WeatherForecastAPI()
    
    def optimize_cooling(self):
        # Real-time data collection
        current_temps = self.sensors.get_temperature_data()
        server_loads = self.sensors.get_compute_utilization()
        weather_forecast = self.weather_api.get_24h_forecast()
        
        # ML prediction for optimal cooling
        optimal_cooling = self.ml_models.predict_cooling_needs(
            temperatures=current_temps,
            compute_load=server_loads,
            weather=weather_forecast,
            time_of_day=datetime.now().hour

        # Automated control adjustment
        self.control_systems.adjust_cooling_setpoints(optimal_cooling)
        
        return {
            'energy_saved_kwh': optimal_cooling.energy_savings,
            'cost_saved_inr': optimal_cooling.energy_savings * 6.50,  # ₹6.50/kWh
            'carbon_reduced_kg': optimal_cooling.energy_savings * 0.82  # 0.82kg CO2/kWh India grid
